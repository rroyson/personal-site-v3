## Quality bar
- brittanychiang.com: the Spotlight canon itself. Sticky statement column, rule-line nav, right column that scrolls, real project screenshots, one accent. The layout Rob chose.
- emilkowal.ski: restraint as finish. Tiny type, sentence-case section heads, no decoration, huge air.
- rauchg.com: a list is enough when the content is real. Plain text, numbers as proof, nothing else.
- paco.me: a three-column index of real links; one italic serif phrase as the single expressive gesture.
- leerob.com: one authored image beside restrained text carries all the personality.
- rauno.me: one giant statement and one bold shape. Proof that a single rule-break is plenty.

## Borrow
- Palette/material: brittanychiang.com -> near-black ground, slate body, one warm accent, hairline lift on hover. Kept, with amber instead of teal.
- Type/hierarchy: emilkowal.ski, rauchg.com -> one family (Geist), weight and color carry hierarchy, no display face.
- Layout/composition: brittanychiang.com -> sticky aside with name, role, one-liner, section nav, socials; section headings only exist on phones.
- Motion/interaction: brittanychiang.com -> cursor spotlight; rows lift on hover. Rob's own ask -> a sparse "neural net" constellation, canvas 2D, no libraries.
- Asset language: brittanychiang.com -> real screenshots of the work, bordered, small. leerob.com -> one real photo of the person.

## Avoid
- Abstract line-art thumbnails standing in for real work.
- Accent-tinted tag clouds; 13 amber pills in a row is wallpaper.
- Uppercase letterspaced eyebrows repeated on every desktop section when the nav already names them.
- Metaphor worlds and costume (stream notation, vinyl, azulejo, mezzotint), all rejected by Rob.
- Animation libraries, WebGL, scroll-jacking. Rob asked for light and fast.
- Invented stats, employer names, testimonials. PRODUCT.md forbids them.

## Direction contract
- Thesis: the two-column developer portfolio recruiters already trust, executed at the level of the best in its category, with real proof where the category usually puts decoration.
- First viewport: left, photo, name, role, one line, rule-line nav, socials pinned low; right, About then the start of Streams; a faint constellation across the whole ground that warms amber near the pointer.
- System: Geist only; ground/ink/body/mute plus one amber; 4/6/8px radii; hairline borders and a faint lift, no shadows; 160-250ms ease-out color and transform transitions; one canvas moment.
- Risk: reading as a Brittany Chiang template. Guarded by real captures, the photo, plain-text tech lists, and hidden desktop eyebrows.
